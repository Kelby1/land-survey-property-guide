# Property Guide — Land Survey Concept 04

A calm, client-first land-survey website concept for property owners who may not know which technical survey service they need.

## Features
- Responsive desktop, tablet, and mobile layout
- Guided “what do I need?” survey selector
- Plain-language project journey
- Interactive property-document checklist
- Expandable FAQ
- Local project-summary builder and copy action

## Preview
Open `index.html` directly in a browser.

## Deployment
This repository is intentionally **not connected to Netlify**, so changes here do not consume the Netlify credits being reserved for the existing live projects.

## Important
The website is a concept only. It does not submit or store project information. Company identity, professional licenses, personnel, equipment, service coverage, and final claims must be confirmed before publication.
